# GreenTrack – Carbon Footprint Tracker

## Overview
A simple full-stack app to estimate and visualize your carbon footprint based on financial transactions.

## Features
- Mock or Plaid-based transaction analysis
- Estimates carbon output by category
- Visual charts of your monthly impact

## Tech Stack
- Frontend: React, Chart.js
- Backend: Node.js, Express
- Data Source: Plaid API (mocked)

## Setup
1. Install backend and frontend dependencies
2. Add `.env` file with API keys if needed
3. Start backend: `node server/index.js`
4. Start frontend in `client/` with `npm start`
